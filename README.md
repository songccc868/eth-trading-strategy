# ETH 技术交易方法

一套多周期技术分析交易方法，封装为可直接运行的判断工具。输入实时行情，输出当前 regime、信号与仓位建议（买/卖/不动、份数、市价/限价）。

> 本仓库只存**方法本身**，不含任何实盘仓位、真实止盈阶梯等正在交易的参数——与作者在 Notion 上的提示词管理原则一致：参数在调用时由本地配置提供。

## 方法概要

**多周期分工**

- 周线：定战略背景（周收盘 vs 周 EMA20，跌破触发大级别风控）
- 日线：定趋势方向（收盘 vs 日 EMA20，首次跌破触发减仓）
- 4H：唯一触发层（所有买卖信号在此产生）
- 1H：只做确认与背离警讯，永不单独触发
- 15m/30m：只优化限价单挂单价

**指标与计算规范**

- EMA20/50/200、MACD(12,26,9)、RSI(14)、KDJ(9,3,3)、成交量比
- ADX(14) 必须用 Wilder 平滑（普通 EMA 会严重高估 ADX 并误判 regime）
- 每次运行先做锚点回归校验：2026-10-01T16:00Z 的 4H K 线，Wilder ADX 应 ≈19.37；校验不过，工具拒绝输出任何信号
- 只用已收盘 K 线判断；实时价只用于限价备选的偏离判断

**动态箱体（不使用固定价位）**

- 箱体 = 最新已收盘 K 线之前 60 根 4H K 线的最高/最低范围
- 下沿买入区 = 箱体底部 35%；上沿区 = 顶部 8%；深跌区 = 下沿下方 2.4%~4.2%；突破位 = 箱体上沿

**信号与确认**

- MACD 交叉需确认才算信号：交叉后第二根同向确认，或交叉当根柱体足够强；区间市（ADX<20）里交叉不单独行动
- 区间边缘看企稳/滞涨形态（长影线、KDJ 拐头、RSI 回升）
- 放量突破 = 收盘站稳箱体上沿 + 量比 >1 + ADX 上穿/上行
- 风控只在“首次收盘跌破”时触发；持续在线下方是状态提示，不重复触发
- 确认信号若价格已偏离信号价 >1%，同时给出挂实际支撑/压制线的限价备选

**仓位框架**

- 核心 + 卫星：核心仓吃大趋势，卫星仓做 4H 区间/信号波段
- 资金按 100 份计，每个信号固定份数；止盈用阶梯（见参数配置）

**背景层（影子模式，只记录不触发）**

- BTC 市场 beta（BTC 4H vs EMA20、MACD 方向、ETH/BTC 比率）
- 加密情绪（恐惧贪婪指数、ETH 永续资金费率、未平仓量）

## 使用

```bash
python3 method.py
```

- 数据源：Kraken 公共行情（ETHUSD 周/日/4H/1H），情绪数据来自 alternative.me 与 OKX 公共接口，无需任何密钥
- 输出：JSON 打印到 stdout，并保存为同目录 `last_output.json`
- 参数（本地，不入库）：
  - `method_config.json`：止盈阶梯，格式见 `method_config.example.json`；缺失时使用内置示例阶梯并在输出中标注 `ladder_source: "example"`
  - `position.json`（可选）：当前仓位 `{"eth_pct": 数字, "cash_pct": 数字}`；缺失时按空仓处理

工具只做判断支持，不执行任何交易。
